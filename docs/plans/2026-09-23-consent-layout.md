# Consent panel reference layout

Visual thesis: a quiet white rounded panel with generous spacing and pill actions.
Content: title, actual tracking explanation, policy link, actions; optional details
expand through the labelled settings icon. Ignore decorative top-right icons.
Interaction: restrained hover/focus feedback; no decorative motion. Preserve
footer access, required opt-in and equally accessible accept/reject actions.
Verify desktop/mobile consent flows and inspect the local preview.
